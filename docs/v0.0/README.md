# v0.0 historical archive

These documents preserve the project's earlier decisions and designs. They may
contain superseded commands, incomplete task lists, old API paths, or claims that
were true only at a particular commit. They are **not** the current source of
truth for runtime behavior. The former `.kiro` files are archived here because
Kiro is no longer used; their Kiro front matter has no active effect.

| Directory | Contents |
| --- | --- |
| [api](api/) | Frozen interface v1 and its v2 delta. Interface v1's API semantics and fields are unchanged by the move. |
| [backend](backend/) | Rebuild plan, API gap register, handoff, and historical changelog. |
| [frontend](frontend/) | Changelog and former customer/admin requirements, designs, UX spec, tasks, and demo checklist. |
| [product](product/) | Former product steering and improvement proposal. |
| [conventions](conventions/) | Former technology and frontend conventions. |
| [history](history/) | Branch merge plan and pre-merge architecture image. |

The merge plan and the old task/checklist files are retained for provenance;
unchecked boxes are not a current work queue. The separate `evals/results.md`
has deliberately not been moved or edited in this pass.
